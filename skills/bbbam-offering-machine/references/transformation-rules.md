# Offering Machine Transformation Rules

## 1. Choose the Emotional Promise

| Promise | What the machine performs |
|---|---|
| Comfort | gathers, warms, shelters, returns |
| Celebration | lifts, multiplies, presents, releases |
| Nostalgia | captures, replays, fades, returns |
| Craving | attracts, circulates, portions, dispenses |
| Reward | accumulates, unlocks, reveals, serves |
| Companionship | pairs, passes, shares, echoes |
| Focus | collects input, concentrates, feeds back |
| Preservation | washes, holds, refreshes, replenishes |
| Daily ritual | repeats, refills, times, returns |

## 2. Inventory the Source

Identify:

- hero object or constellation;
- container/base;
- linear element;
- circular edge or opening;
- moving material or sensory trace;
- repetition;
- human contact or environmental support.

Use only what exists. Omit categories the source does not provide.

## 3. Build a Function Map

Assign at least three different functions.

| Source cue | Functions |
|---|---|
| tray / plate / package | basin, stage, collector, return field |
| cup / shell / box | reservoir, chamber, dispenser |
| straw / handle / cable / spoon | conduit, rail, lifting arm, scoop |
| rim / crust / lid | gate, orbit, carousel, portion wheel |
| steam / liquid / reflection | visible current, signal, output |
| repeated pieces / keys | procession, measured portions, mini-offerings |
| hand / shadow / table edge | support, lever, boundary |

Never map every line to “a tube” or every circle to “an orbit.”

## 4. Write the Causal Ritual

Complete:

> “The machine collects [input] from [source part], moves it through [mechanism], transforms or portions it at [mechanism], dispenses [output], then returns or presents it through [final mechanism].”

Require at least three linked verbs. Make the moving substance visible. If the process cannot be explained in one sentence, simplify or redesign.

## 5. Compose the Apparatus

Use:

- one base/stage;
- one hero constellation;
- 3–6 connected mechanisms;
- one visible current;
- one family of outputs/signals.

Allow several gestures—cradle, orbit, conveyor, fountain, dispenser, scoop, return channel—when they form one process. Do not restrict the design to one decorative gesture.

Balance:

- hero: 45–65%;
- mechanisms: 25–40%;
- output/signals: 5–15%.

## 6. Set Transformation Strength

Aim for 70–85% transformation of spatial behavior and meaning while preserving identity, appetite, touch, and key silhouettes. Change scale, grouping, function, circulation, and viewpoint enough to create an impossible kinetic still life.

Reject polished product photography and product-design concepts. The machine must perform, not merely look engineered.

## 7. Select Materials

- Preserve hero material exactly enough to remain attractive.
- Choose one apparatus pair: polished steel + clear acrylic; pearl ceramic + satin aluminum; frosted acrylic + soft enamel; paper + translucent membrane.
- Let the moving signal inherit the hero's appetizing or emotional color.
- Use glass/metal for rails, collectors, gates, or supports—not every surface.

## 8. Prompt Contract

> “Image 1 is the source. Image 2 is a positive reference for ritual abundance, kinetic causality, hero hierarchy, and polished market-automaton composition; do not copy its specific food or mechanism layout.
>
> Hero constellation: [objects]. Emotional promise: [promise]. Preserve [identity/tactile qualities].
>
> Source map: [part→function, part→function, part→function]. Causal ritual: [collect → move → transform/portion → dispense/present → return].
>
> Build one coherent apparatus with a base, 3–6 connected mechanisms, one visible current, and one family of outputs. Show it mid-operation. Keep every mechanism source-derived and process-relevant. Use [materials/colors/light]. Transform spatial behavior by 70–85%.
>
> No product redesign, appliance concept, simple charger, decorative orbit, generic pipes, unsupported cables, random sci-fi parts, shrine cliché, dense mechanical clutter, dark cyberpunk, sterile laboratory, or loss of appetite/warmth.”

## 9. Rejection Tests

- **Hero:** does the source pleasure remain instantly recognizable and desirable?
- **Causality:** can a viewer follow three or more linked actions?
- **Motion:** is a visible material, signal, or object moving through the system?
- **Derivation:** can every major mechanism be traced to the source?
- **Transformation:** did role, scale, grouping, circulation, and spatial behavior change substantially?
- **Appliance:** does it look purchasable as a normal gadget? Reject.
- **Product photo:** remove the apparatus mentally; if only retouching remains, rebuild.
- **Swap:** if another object could use the same machine unchanged, strengthen source-specific behavior.
- **Clutter:** if a part has no causal role, remove it.
- **Warmth:** if food looks synthetic or the object feels ominous, revise.
